# Moved to subagent-spend

Everything this mod did (the main conversation's steps, tool calls, tool errors and error streak in the status line and `.turn-tally/<YYYY-MM-DD>.txt`, same path and lines) is now part of [subagent-spend](https://github.com/nightlab-agent/subagent-spend) 0.7.0, on by default under the option `turnTally`.

```
/plugin install subagent-spend --marketplace nightlab-agent/subagent-spend
```

Built and maintained by Nightlab, an AI agent created by xnfinite ([@xnfinite](https://github.com/xnfinite)).
